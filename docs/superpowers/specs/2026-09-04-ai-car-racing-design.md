# AI Car Racing - спецификация

Дата: 2026-09-04
Статус: утверждено

## 1. Что это

Игра-песочница на pygame. Раунд состоит из трёх шагов:

1. Нейросеть-генератор рисует гоночную трассу.
2. Нейросеть-генератор рисует машинку и её физические параметры.
3. Нейросеть-водитель обучается эволюцией проезжать эту трассу от старта до финиша.

Раунды запускаются по кругу с новыми генерациями. Статистика копится между запусками, лучшие мозги сохраняются на диск.

## 2. Стек

Python 3.13, pygame 2.6.1, numpy 2.4.4. Внешних ассетов нет: формы, звуки и графика генерируются кодом. pytest для тестов.

## 3. Файлы

| Файл | Ответственность |
|---|---|
| `main.py` | игровой цикл, машина состояний раунда |
| `config.py` | значения по умолчанию |
| `cppn.py` | CPPN: сборка сети из генома, прогон, форма из радиусов |
| `evolution.py` | ГА: турнирный отбор, скрещивание, мутация, элита |
| `track.py` | генерация и эволюция трассы, стены, чекпоинты, проверки геометрии |
| `car.py` | форма и параметры машинки, векторная физика популяции |
| `sensors.py` | лучи-датчики, пересечение луча со стенами |
| `brain.py` | сеть водителя, прогон всей популяции одной матрицей |
| `render.py` | отрисовка трассы, машинок, лучей, камера |
| `ui.py` | боковая панель: кнопки, ползунки, график |
| `sound.py` | синтез звуков |
| `stats.py` | сбор статистики, сохранение и загрузка |

Данные лежат в `saves/`: геномы в `.npz`, история в `stats.json`.

### Поток данных

```
seed -> track.evolve()  -> centerline, walls, checkpoints
seed -> car.generate()  -> silhouette, mass, power, max_steer
                              |
brain population (50 x 112) --+--> sensors -> brain -> steer/throttle -> physics
                                                              |
                                                        fitness (50,)
                                                              |
                                                        evolution.step()
```

## 4. Генератор трассы

CPPN: вход `(sin θ, cos θ)`, три скрытых слоя по 8 нейронов, активации перемешаны (`sin`, гауссиана, `tanh`, `abs`), выход - радиус `r`. Синус и косинус на входе гарантируют замкнутость: при θ=0 и θ=2π вход одинаковый.

θ пробегает 360 значений. `r` нормируется в `[R_MIN, R_MAX]`, точки переводятся в декартовы координаты, кривая сглаживается скользящим средним.

Геном трассы - веса CPPN, около 200 чисел.

### Отбор и эволюция

Популяция 200 геномов, 15 поколений. Приспособленность трассы:

- самопересечений нет (иначе приспособленность 0)
- минимальный радиус поворота больше радиуса разворота машинки (иначе 0)
- длина в пределах `[LEN_MIN, LEN_MAX]`, отклонение штрафуется
- разнообразие кривизны: стандартное отклонение кривизны вдоль трассы, это основная награда

Ползунок "сложность" поднимает требуемый порог разнообразия кривизны.

### Стены и чекпоинты

Стены - центральная линия, сдвинутая на `±TRACK_WIDTH/2` по нормали. Чекпоинты - поперечные отрезки от стены до стены через каждые `CHECKPOINT_STEP` точек центральной линии, пронумерованы по порядку. Старт и финиш на θ=0.

## 5. Генератор машинки

CPPN проще: вход `(sin φ, cos φ)`, два скрытых слоя по 6, выход - радиус силуэта. 24 точки по кругу дают многоугольник кузова вид сверху.

Физика выводится из формы, а не задаётся отдельно:

- площадь силуэта -> масса
- отношение длины к ширине -> максимальный угол поворота руля (длинная узкая машина поворачивает хуже)
- масса и длина -> мощность двигателя, отмасштабированная так, чтобы машина оставалась управляемой

Цвет берётся из генома.

## 6. Водитель

Вход - 8 чисел:

- 7 лучей под углами -90, -60, -30, 0, 30, 60, 90 градусов, расстояние до стены, нормированное в `[0, 1]` делением на `RAY_MAX`
- текущая скорость, нормированная на максимальную

Скрытый слой 10 нейронов, `tanh`. Выход 2 числа, `tanh`: руль `[-1, 1]` и газ `[-1, 1]` (отрицательный газ - торможение).

Размер генома: 8*10 + 10 + 10*2 + 2 = 112.

Вся популяция считается одной операцией: `np.einsum` по матрице весов `(50, 8, 10)`.

### Приспособленность

```
fitness = checkpoints_passed * 100
        + progress_in_current_segment * 100
        + (finish_bonus if finished else 0)
```

`finish_bonus = (STEPS_PER_GEN - steps_used) * 0.5`, то есть быстрее доехал - больше награда.

Машинка умирает при касании стены. Дополнительно: если новый чекпоинт не взят за `IDLE_LIMIT` шагов, машинка тоже умирает. Это убирает стратегию "крутиться на месте".

### Генетический алгоритм

Элита `ELITE_FRAC` переходит без изменений. Остальные - потомки: турнирный отбор по 3, равномерное скрещивание (каждый ген с вероятностью 0.5 от одного из родителей), гауссова мутация с силой `MUT_SIGMA` и вероятностью `MUT_RATE` на ген.

`evolution.py` не знает, что за геном ему дали. На вход массив `(N, G)` и массив приспособленностей `(N,)`, на выход новый массив `(N, G)`. Используется и для трасс, и для мозгов.

## 7. Физика

Модель без заносов, чистая кинематика. Состояние популяции: `pos (50, 2)`, `angle (50,)`, `speed (50,)`, `alive (50,)` булев.

Шаг:

```
speed += throttle * power / mass - speed * DRAG
speed  = clip(speed, 0, max_speed)
angle += steer * max_steer * (speed / max_speed)
pos   += [cos(angle), sin(angle)] * speed * dt
```

Умножение на `alive` замораживает мёртвые машинки. Ни одного `if` по машинкам, всё маски.

Столкновение: минимальное расстояние по лучам меньше `car_width / 2`.

## 8. Цикл игры

Состояния:

- `TRACK_GEN` - эволюция трассы, доли секунды
- `CAR_GEN` - генерация машинки, мгновенно
- `TRAINING` - поколения идут одно за другим, видно на экране
- `SHOWCASE` - показательный заезд лучшего мозга, камера следует за машинкой
- `PAUSED`

Поколение заканчивается, когда все машинки мертвы или прошло `STEPS_PER_GEN` шагов. Обучение заканчивается по `MAX_GENERATIONS` или когда лучший доехал до финиша.

Скорость симуляции: x1, x5, x20, "без отрисовки". Реализуется как N шагов физики за один кадр, рисуется только последний. Режим "без отрисовки" считает поколение целиком за кадр.

## 9. Интерфейс

Окно 1280x720. Слева трасса целиком, масштаб подгоняется под её габариты. Справа панель шириной 300.

Панель сверху вниз:

- поколение, живых из N, лучшая приспособленность, средняя, процент доехавших, лучшее время
- график лучшей и средней приспособленности по поколениям, рисуется линиями
- ползунки: размер популяции, число поколений, сила мутации, доля элиты, ширина трассы, сложность трассы, громкость
- переключатели: скорость симуляции, "с нуля / продолжить с лучшим мозгом"
- кнопки: новый раунд, новая трасса, показательный заезд, сохранить мозг, загрузить мозг

Изменение размера популяции применяется со следующего раунда, остальные ползунки действуют сразу.

Мёртвые машинки остаются на экране бледными, видно место массовых аварий. У лидера рисуются лучи-датчики.

## 10. Звук

Всё синтезируется numpy при старте, файлов нет.

- двигатель: 12 зацикленных пилообразных сэмплов на разных частотах, по скорости лидера выбирается нужный и плавно переключается
- удар о стену: всплеск белого шума с экспоненциальным затуханием, около 120 мс
- финиш: три ноты вверх

Звук берётся только от лидера. Если аудиоустройства нет, `pygame.mixer.init()` падает - ловим и работаем молча.

## 11. Сохранение

`saves/brains.npz` - лучшие геномы с их приспособленностью. `saves/stats.json` - всего раундов, трасс пройдено, лучшее время, среднее число поколений до финиша.

Загрузка мозга с несовпадающим размером генома (поменяли число лучей или скрытый слой) отбрасывается с сообщением в панели, обучение начинается с нуля.

## 12. Краевые случаи

- Эволюция трассы не нашла ни одного валидного гена за 15 поколений: смягчаем требования (порог кривизны вниз, пределы длины шире) и пробуем ещё раз, максимум 3 попытки, потом берём круг.
- Все машинки в первом поколении умерли мгновенно и приспособленность у всех нулевая: турнирный отбор вырождается, поэтому при нулевой дисперсии приспособленности популяция генерируется заново случайно.
- Луч не пересёк ни одну стену: возвращаем `RAY_MAX`.
- Ползунок размера популяции меняет форму матриц, поэтому применяется только между раундами.

## 13. Тесты

pytest, только то, что проверяется без графики:

- трасса замкнута, первая и последняя точка совпадают
- сгенерированная трасса не имеет самопересечений
- чекпоинты идут по порядку вдоль центральной линии
- мутация сохраняет размер генома
- скрещивание даёт гены только от родителей
- мёртвая машинка не меняет позицию после шага физики
- пересечение луча с известным отрезком даёт правильное расстояние
- приспособленность растёт при взятии чекпоинта

Графика и звук проверяются глазами.
