# cppn.py

Генератор форм. Превращает вектор чисел (геном) в замкнутый контур: трассу или силуэт машинки.

Модуль не знает, что он рисует. Он умеет только одно: взять угол и вернуть радиус. Всё остальное решает вызывающая сторона через параметры `n_points`, `r_min`, `r_max`.

## Что такое CPPN

CPPN расшифровывается как Compositional Pattern Producing Network, сеть, порождающая узоры. От обычной нейросети её отличают две вещи.

Первое: веса не обучают. Их берут случайными, и этого уже достаточно, чтобы получить осмысленную форму. У обычной сети случайные веса дают мусор, здесь нет.

Второе: разные нейроны используют разные функции активации, причём периодические и симметричные. Синус даёт повторяющиеся детали, гауссиана локальные выступы, тангенс плавные переходы, модуль изломы. Композиция таких функций от координаты порождает узоры, похожие на природные: симметрию, повторы, плавные переходы между зонами.

Подход придумал Кеннет Стэнли, тот же человек, что придумал NEAT. На нём работает Picbreeder, где люди эволюционируют картинки без всякого обучения на данных.

Для нас важно следствие: чтобы получить трассу, датасет трасс не нужен. Нужен только набор случайных чисел.

## Почему на входе синус и косинус, а не сам угол

Ключевая деталь всего модуля.

Контур строится так: угол θ пробегает от 0 до 2π, для каждого θ сеть выдаёт радиус r(θ), точка кладётся в `(r·cos θ, r·sin θ)`. Чтобы контур замкнулся, нужно `r(0) = r(2π)`.

Если подать в сеть само число θ, то на входе будет 0 в начале и 6.28 в конце. Сеть выдаст разные радиусы, и концы кривой не сойдутся. Получится спираль с разрывом.

Если подать `(sin θ, cos θ)`, то при θ=0 вход равен `(0, 1)` и при θ=2π он тоже равен `(0, 1)`. Одинаковый вход даёт одинаковый выход. Замкнутость выполняется по построению, а не подгонкой.

Побочный плюс: пара синус-косинус это точка на единичной окружности, то есть сеть получает угол в виде, где нет разрыва при переходе через ноль. Тот же приём применяют, когда подают время суток или день года в обычную модель.

## Почему активации перемешаны по индексу нейрона

В `_mixed` нейрон номер `j` получает активацию `ACTS[j % 4]`. То есть в слое из 8 нейронов будет два синуса, две гауссианы, два тангенса и два модуля.

Если поставить одну активацию на всю сеть, формы получатся однообразные. Только синусы дают волнистые кольца, только тангенсы дают почти круги.

Перемешивание идёт по индексу, а не случайным выбором. Это важно: случайный выбор пришлось бы либо хранить в геноме, либо каждый запуск давал бы для одного и того же генома разную форму. Привязка к индексу делает функцию `ring_shape` чистой, и seed воспроизводит трассу точь-в-точь.

## Почему выход всегда tanh

Последний слой всегда `tanh`, независимо от `_mixed`. Нужен гарантированно ограниченный диапазон `[-1, 1]`, чтобы линейно отобразить его в `[r_min, r_max]`:

```
r = r_min + (out + 1) / 2 * (r_max - r_min)
```

Если бы выход был неограничен, радиусы уезжали бы в тысячи пикселей и трасса не влезала бы на экран.

## Почему разброс весов 1.5, а не 1

`CPPN_INIT_SCALE = 1.5` в `config.py`. При маленьких весах суммы на входе активаций близки к нулю, а там `tanh` и `sin` почти линейны. Композиция почти линейных функций это почти линейная функция, и на выходе получается ровный овал.

Разброс 1.5 загоняет аргументы в нелинейную область, где синус успевает сделать пол-периода, а гауссиана заметно спадает. Формы становятся разнообразными.

## Функции

### `genome_size(layers) -> int`

Сколько чисел нужно для сети с заданной топологией. `layers` это кортеж размеров слоёв, например `(2, 8, 8, 8, 1)`.

Считает веса плюс смещения для каждой пары соседних слоёв.

```python
>>> cppn.genome_size((2, 8, 8, 8, 1))
177
>>> cppn.genome_size((2, 6, 6, 1))
67
```

### `forward(genome, layers, x) -> ndarray`

Прогон сети. `x` имеет форму `(N, layers[0])`, результат `(N, layers[-1])`.

Бросает `ValueError`, если длина генома не совпадает с топологией. Это ловит самую противную ошибку в проекте: загрузили сохранённый геном после смены числа слоёв, и он молча переинтерпретировался как другая сеть.

### `ring_shape(genome, layers, n_points, r_min, r_max) -> ndarray`

Главная функция. Возвращает `(n_points, 2)` точек замкнутого контура вокруг начала координат.

Углы берутся через `np.linspace(0, 2π, n_points, endpoint=False)`. Флаг `endpoint=False` обязателен: с ним последняя точка не совпадает с первой, а стоит на один шаг раньше. Иначе в массиве была бы дублирующая точка, и все расчёты длины и кривизны через `np.roll` дали бы нулевой отрезок в одном месте.

```python
import numpy as np
import cppn
import config as cfg

rng = np.random.default_rng(7)
g = cppn.random_genome(cfg.TRACK_CPPN_LAYERS, rng)
pts = cppn.ring_shape(g, cfg.TRACK_CPPN_LAYERS, cfg.TRACK_POINTS, cfg.R_MIN, cfg.R_MAX)
print(pts.shape)                      # (360, 2)
print(np.linalg.norm(pts, axis=1)[:5])  # первые пять радиусов
```

### `random_genome(layers, rng, scale=cfg.CPPN_INIT_SCALE) -> ndarray`

Случайный геном из нормального распределения. `rng` это `np.random.default_rng(seed)`, передаётся снаружи, чтобы весь проект воспроизводился по одному seed.

## Связи

`track.py` вызывает `ring_shape` с `TRACK_CPPN_LAYERS` и получает центральную линию.

`car.py` вызывает `ring_shape` с `CAR_CPPN_LAYERS` и получает силуэт кузова.

`evolution.py` работает с геномами CPPN как с обычными векторами и ничего не знает про этот модуль.
