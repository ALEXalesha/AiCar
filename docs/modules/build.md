# build.py и installer.nsi

Сборка портативной версии и установщика для Windows.

```
pip install pyinstaller pillow
python build.py
```

На выходе три вещи (2.0.0):

| Что | Размер | Для чего |
|---|---|---|
| `dist/AiCar/` | 95 МБ | готовая папка с `AiCar.exe` |
| `dist/AiCar-2.0.0-portable.zip` | 39 МБ | распаковал и играешь, ничего не устанавливая |
| `dist/AiCar-2.0.0-setup.exe` | 28 МБ | установщик с ярлыками и деинсталлятором |

Python, numpy и Qt (PySide6) внутрь уже упакованы, у игрока ничего ставить не надо. У pygame-версии 1.1.0 было 68 / 30 / 20 МБ: Qt больше, и из него убрано всё, что игре не нужно (ниже).

Номер версии - один, в `installer.nsi` (`!define VERSION`); по нему названы и установщик, и архив. 2.0.0 - мажорная: сменился движок окна.

## Иконка

Рисуется тем же кодом, что значок окна и машинки в игре (`render.icon_image(render.icon_car())`): фиксированный геном, машинка носом вверх на скруглённом тёмном квадрате. Qt рисует её без экрана (offscreen) в PNG, Pillow собирает `.ico` со всеми размерами от 16 до 256 пикселей.

Готового файла иконки в репозитории нет намеренно: поменяется вид машинок, поменяется и иконка.

## PyInstaller

Собирается в режиме одной папки, а не одного файла. Один файл выглядит опрятнее, но при каждом запуске распаковывает почти сотню мегабайт во временную папку, и старт занимает секунды. Папка стартует мгновенно.

`--windowed` убирает окно консоли. Побочный эффект: `print` некуда выводить (`sys.stdout` - `None`), поэтому проверка сборки сделана через ключ `--selftest`, который пишет отчёт в файл, а печатает, только если есть куда.

### Что исключено и почему

**`EXCLUDE`** - модули, которые PyInstaller потянул бы по импортам: torch, scipy, sklearn, pandas и другие тяжёлые библиотеки из окружения; pygame и tkinter; PIL (нужен только самой сборке); модули Qt, которых игра не импортирует (Quick, QML, WebEngine, PDF, Charts, 3D, Test и десяток других - на случай, если зависимость что-то притащит); `ssl` - его тянут `urllib` и `http.client` из `numpy.lib._datasource`, а оба живут без него (`import ssl` у них в `try`).

**`trim`** - то, что PyInstaller всё равно кладёт за компанию, после сборки удаляется:

| Что | Почему не нужно | Сколько |
|---|---|---|
| `Qt6Quick`, `Qt6Qml*`, `Qt6VirtualKeyboard`, плагин экранной клавиатуры | клавиатуру тянет плагин ввода, а она - Qt Quick и QML | 13 МБ |
| `opengl32sw.dll`, `Qt6OpenGL` | окно рисуется без OpenGL | 22 МБ |
| FFmpeg (`avcodec`, `avformat`, `avutil`, `swresample`, `swscale`) и его плагин | это видео и сжатый звук для `QMediaPlayer`; игра пишет свой синтез в `QAudioSink` | 19 МБ |
| OpenSSL и плагины TLS, плагин сетевого состояния | игре не нужна сеть | 12 МБ |
| `Qt6Svg`, `Qt6Pdf`, их плагины | картинок SVG и PDF нет | 5 МБ |
| платформы `direct2d`, `minimal` | нужны `windows` (окно) и `offscreen` (самопроверка) | 1 МБ |
| переводы Qt, кроме русского | интерфейс по-русски | 7 МБ |

Всё это проверено запуском собранной игры, а не по названиям: `AiCar.exe --selftest` после чистки открывает окно offscreen, находит шрифт Consolas, открывает звуковую карту (48000 Гц, стерео - без FFmpeg), доигрывает раунд с тем же результатом, что из исходников; и `AiCar.exe` без ключа открывает настоящее окно.

Мораль, выученная ещё на pygame (`setuptools` исключили - сборка падала на `jaraco` при старте): исключать по названию нельзя, только с проверкой запуском. `pkg_resources`, который нужно было добавлять ради pygame, больше не нужен.

## Портативная версия

Отличается от установленной ровно одним файлом: рядом с exe кладётся `portable.txt`. Пока он там, игра пишет сохранения, статистику, настройки (`settings.json`) и место окна (`window.json`) рядом с собой, а не в профиль пользователя. Установщик этот файл удаляет. В архив кладутся оба README и LICENSE.

Так одна и та же сборка работает в обоих режимах, и собирать дважды не надо. Подробности в [paths.md](paths.md).

## Установщик

NSIS, скрипт `installer.nsi`.

Ставится в `%LOCALAPPDATA%\Programs\AiCar`, а не в `Program Files`. Поэтому не нужны права администратора: `RequestExecutionLevel user`. Для игры это правильный выбор, окно UAC на ровном месте раздражает.

Создаёт ярлыки в меню Пуск и на рабочем столе, прописывается в список установленных программ, кладёт рядом деинсталлятор.

При удалении спрашивает отдельно, сносить ли сохранения, статистику и настройки из `%LOCALAPPDATA%\AiCar`. По умолчанию оставляет: переустановка игры не должна стирать рекорды. Обновление 1.1.0 до 2.0.0 их читает (тесты совместимости на файлах 1.1.0).

## Проверка сборки

```
dist\AiCar\AiCar.exe --selftest C:\путь\отчёт.txt
```

Игра прогоняет полный раунд обучения через настоящее окно, только без экрана (платформа offscreen, шрифты из папки Windows), рисует меню, статистику и настройки, открывает звуковую карту с нулевой громкостью и пишет отчёт. Мозги и статистика пишутся при этом во временную папку (`stats.use_sandbox`), так что проверка установленной игры не портит рекорды игрока:

```
запуск из архива: True
папка данных:     C:\Drive\Alexey\AiCar\dist\AiCar
модель трасс:     есть (...\_internal\models\track_vae.npz)
звук:             есть
формат звука:     48000 Гц, каналов 2 (QtMultimedia, int16)
платформа Qt:     offscreen
шрифт:            Consolas 15 px
трасса:           длина 1940, чекпоинтов 45
обучение:         поколений 4, состояние done
лучший результат: 4971
кадр:             3.7 мс в среднем, кадров 197, 1280x720
статистика:       экран 1280x720, раундов 1
экраны:           меню, игра, статистика, настройки - нарисованы
OK
```

Строка «лучший результат» важнее всех остальных: он совпадает с запуском из исходников до единицы - и с отчётом pygame-версии 1.1.0 тоже (`длина 1940, поколений 4, 4971`). Значит смена окна не тронула ни трассу, ни обучение, сборка ничего не потеряла и не подменила, а модель трасс нашлась внутри архива. Расходиться имеют право только первые строки, потому что у собранной версии другие пути, и время кадра.

Строка «звук» - по настоящему устройству, а не по заглушке: у Qt её нет, и так даже лучше - первая сборка 2.0.0 именно здесь показала «нет, устройство не открылось (NoError)» и тем нашла ошибку в сравнении кода ошибки (`sound.md`). Строка «шрифт» говорит, нашёлся ли Consolas у платформы offscreen: без папки шрифтов Windows вместо букв были бы квадратики.

Проверять надо оба режима: с `portable.txt` и без него. Во втором случае в отчёте появляется папка профиля (`%LOCALAPPDATA%\AiCar`), и в ней после прогона ничего не меняется.
